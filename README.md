# CK3-mod-translator-from-AI
Браузерный (навайбкоженный, фу фу) переводчик модов для CK3 для другого переводчика для тех кто лох и у кого не работало через него.
Хер знает кому это вообще будет надо, засранец-автор другой проги для которой и делалась эта шняга вроде уничтожил смысл существования этой шняги (почти) ровно 15 минут назад своей обновой, лмао


Крч. Ввиду неприятных ситуаций пришлось самому выдрачивать перевод мода. Эта чухня работает в рамках браузера при запущенной в powershell локалхоста по которому это надо открывать. Сделано это ради того чтобы можно было покрыть всё это дело впн-ом браузерным расширением.
Теперь конкретно об этой фиче. Это сайтик имеющий при себе скрипт на Java Script. После того как правильно запустили у него есть соответствующие поля по выбору хостинга (типа нейронок) и самих моделей нейроно. Так же выбирается кол-во строк за один запрос, частота запроса, сколько потоков. Если вы крутой перец и платите подписки для нейронок - можно разгонять эту залупу. Вся эта чухня работает в рамках другой проги - CK3 localization manager. Там можно получить файл с текстом который нужно перевести и файл с промтом. Вставляете файл на сайте, промт редачите в самом коде сайта (как и прочие мелочи по желанию). Впоследствии нехитрых махинаций попущенная и выбранная вами нейронка по API ключу будет переводить ту залупу что вам будет нужна. Я так перевёл мод с 12-ю тысячами строк текста. Почти мини-новелла. Мод был порнушный, ес чё. Попутно оно должно фиксить какие-либо недочёты если там проёбки со стороны нейронки будут и так далее, скрипты дополненны инструкциями. Ну и в целом всё. Рот ебал всей этой залупы, 5 ебанных утра, я проебал почти полтора дня из-за одного ебучего мода в ебучей CK3. На что я трачу жизнь?)

Кому если надо и если кто-то это вообще увидит - сможет как-то адаптировать при желании. Правда смысла в существовании этой шняги почти нет.... Но да ладно, хотя бы опубликую причину своих недосыпов и несданных долгов в вузе
